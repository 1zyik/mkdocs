# T1nk3r

> "The best way to learn is to break things... in a controlled environment."

**T1nk3r** is my digital garden and knowledge base. It documents my journey through **DevOps**, **SRE**, and **Homelab** tinkering.

## 🚀 What's Inside?

*   **DevOps Practices**: CI/CD, IaC, and automation.
*   **SRE & Observability**: Monitoring, SLIs/SLOs, and incident management.
*   **Homelab Adventures**: Self-hosted services and networking.

## 🛠️ Local Development

This project is built using Zensical.

```bash
# 1. Navigate to the project directory
cd project_directory

# 2. Create a virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install dependencies
pip install zensical

# 4. Start the development server
zensical serve
```

Enjoy!!!
