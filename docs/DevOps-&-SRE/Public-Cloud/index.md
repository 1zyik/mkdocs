# The Public Cloud

The public cloud is the foundation of modern application development and infrastructure. It represents a paradigm shift from managing physical hardware to provisioning virtual resources on-demand, globally, and at scale.

This section is my digital notebook for exploring the services, architectures, and best practices of the major cloud providers.

## The Big Three

While there are many players, my focus will primarily be on the hyperscalers:

*   **Amazon Web Services (AWS)**: The market leader, known for its sheer breadth and depth of services.
*   **Microsoft Azure**: A strong enterprise player with deep integration into the Microsoft ecosystem.
*   **Google Cloud Platform (GCP)**: A powerhouse in data, analytics, and networking, with a reputation for innovation.

## What to Expect

*   **Core Services**: Deep dives into fundamental building blocks like compute (EC2, VMs), storage (S3, Blob Storage), and networking (VPC, VNet).
*   **Serverless & Containers**: Exploring Lambda, Azure Functions, Cloud Run, and the Kubernetes offerings (EKS, AKS, GKE).
*   **Infrastructure as Code (IaC)**: Using tools like Terraform and CloudFormation to manage cloud resources declaratively.
*   **Cost Management**: Strategies for monitoring, optimizing, and understanding cloud spend.

## The Philosophy

> "The cloud is just someone else's computer."

While true, the magic lies in the abstraction. The public cloud allows individuals and organizations to wield the power of a massive, distributed, and expertly-managed datacenter through an API. This section is about peeling back that abstraction, one service at a time.
